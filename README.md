# Event Superschema Workspace

Multi-language workspace for event superschema implementations and research.

## Repositories

- **python-event-superschema**: Python implementation (existing)
- **node-event-superschema**: Node.js/TypeScript implementation (new)
- **cpp-event-superschema**: C++ implementation (new)
- **cs-event-superschema**: C# implementation (new)
- **paper-event-superschema**: Research paper and documentation (new)

## Development Environment

This workspace uses a Dev Container with support for:
- Python 3.11+
- Node.js 20.x LTS
- .NET 8.0 SDK
- C++ (GCC/Clang) with Boost
- LaTeX (TeX Live)

### Getting Started

1. Open this folder in VS Code
2. When prompted, click "Reopen in Container"
3. Wait for the container to build and start

### Building Projects

Each subdirectory contains its own build instructions and tooling.
